# Bundled Linux YARA rules

These five rules are from [Intezer Labs' public YARA rules](https://github.com/intezer/yara-rules), revision `856a8e54b05add87764ddc35a964423782e13558`, under the accompanying MIT license. They cover a small number of known malware families; they are not a comprehensive or automatically updated threat feed. Matches are shown as findings for review, not definitive malware verdicts.
